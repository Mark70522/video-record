Place ffmpeg.exe here.

Download from: https://github.com/BtbN/FFmpeg-Builds/releases
  -> ffmpeg-master-latest-win64-gpl.zip
  -> extract and copy bin/ffmpeg.exe into this folder

The application looks for ffmpeg.exe in this directory at startup.
If ffmpeg.exe is already on your system PATH, you do not need to copy it here.
